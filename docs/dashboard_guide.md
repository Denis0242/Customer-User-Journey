# Dashboard Guide

## Dashboard Title
Customer User Journey Dashboard

## Dashboard Sections
- KPI summary: total users, conversion rate, D1 retention, D7 retention, revenue per user
- Funnel chart: stage-level customer progression
- Drop-off analysis: conversion friction between stages
- Retention trend: D1 vs D7 retention over time
- Churn risk distribution: customer risk mix
- Conversion by channel: acquisition channel performance
- Revenue by segment: segment-level monetization
- Insight, Action, Recommendation, Decision panel

## Suggested Tableau Filters
- Funnel Stage
- Country
- Segment
- Device
- Risk Category
- Date
- Metric Selector

## Portfolio Positioning
Use this project to show product analytics thinking: funnel analysis, retention analysis, segmentation, risk prioritization, and decision support.
